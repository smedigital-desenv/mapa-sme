Atualizar dados do Boletim
Restrito à Seção de Fluxo Escolar. O sistema reconhece automaticamente dois arquivos:
• DADOS_GERAL (.xlsx) → boletim completo (histórico + metas + 2026).
• 2026.xlsx → atualiza só as seções de 2026, preservando o histórico já gravado.
Para o boletim completo, o ideal é subir o DADOS_GERAL pelo menos uma vez (traz o histórico). Depois, o 2026.xlsx mantém o ano corrente atualizado. O botão só aparece para s.fluxoescolar e super admin.
